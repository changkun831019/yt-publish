隐私政策

适用于「常老师的发布工具」 · 更新日期：2026 年 11 月 23 日

这是什么

「常老师的发布工具」是开发者自己用的命令行小工具，只在开发者自己的电脑上运行，用来把开发者做好的视频传到开发者自己的 YouTube 频道。它不对外提供，也不收集任何其他人的数据。

会访问哪些数据

只有频道主本人登录 Google、在授权页点了“允许”之后，本工具才会通过 YouTube API 服务（YouTube Data API）访问这个频道的以下内容：

  • 频道信息：频道名称、频道 ID、横幅和简介；
  • 视频：上传视频，读取和修改标题、说明、标签、封面、公开状态和定时公开时间；
  • 播放列表：新建播放列表，把视频加进播放列表；
  • 公开统计：播放、点赞和评论的数量。

本工具不访问你的 Gmail、通讯录、云端硬盘，也不访问 Google 账号里的其他数据。

怎么使用这些数据

只用来完成频道主自己发起的操作：上传和修改视频、改频道设置、查看自己频道的数据。不用于广告，不做用户画像，不出售，也不和任何第三方分享。

存在哪里、存多久

授权令牌和操作记录只保存在运行本工具的那台电脑上，文件只有本机账户能读。本工具没有服务器，除了 Google 不把数据传到任何地方。删掉电脑上的令牌文件，或者撤销授权（见下一条），这些数据就不能再用。

怎么撤销授权

随时可以在 Google 账号的安全设置页面撤销本工具的访问权限：https://security.google.com/settings/security/permissions。撤销以后，本工具再也无法访问你的频道。

YouTube 和 Google

本工具使用 YouTube API 服务。使用本工具，即表示你同意受 YouTube 服务条款约束。Google 怎么处理你的数据，见 Google 隐私权政策。

本工具对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的“有限使用”（Limited Use）要求。

儿童

本工具不面向儿童。

变更和联系

本政策有变化时，会更新这个页面和上面的日期。有问题请在 GitHub 仓库里提 Issue。

Privacy Policy

For “常老师的发布工具” (Chang's Publishing Tool) · Last updated: November 23, 2026

What this is

常老师的发布工具 is a small command-line tool for the developer's own use. It runs only on the developer's own computer and uploads videos the developer made to the developer's own YouTube channels. It is not offered to anyone else and collects no data about anyone else.

What data it accesses

Only after the channel owner signs in to Google and clicks “Allow” on the consent screen does the tool use YouTube API Services (the YouTube Data API) to access the following for that channel:

  • Channel information: channel name, channel ID, banner and description;
  • Videos: uploading videos, and reading and changing titles, descriptions, tags, thumbnails, privacy status and scheduled publishing time;
  • Playlists: creating playlists and adding videos to them;
  • Public statistics: view, like and comment counts.

The tool does not access Gmail, contacts, Drive or any other data in your Google Account.

How the data is used

Only to carry out actions the channel owner starts: uploading and editing videos, changing channel settings, and viewing the owner's own channel statistics. The data is not used for advertising or profiling, is not sold, and is not shared with any third party.

Storage and retention

Authorization tokens and operation logs are stored only on the computer that runs the tool, in files readable only by the local user account. The tool has no server and sends no data anywhere except to Google. Deleting the token files, or revoking access (see below), makes this data unusable.

Revoking access

You can revoke the tool's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After you revoke access, the tool can no longer access your channel.

YouTube and Google

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. For how Google handles your data, see the Google Privacy Policy.

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The tool is not directed to children.

Changes and contact

If this policy changes, this page and the date above will be updated. For questions, please open an issue in the GitHub repository.
